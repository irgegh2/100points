# Идеи для развития 100 БАЛЛОВ

Список того, что можно реализовать дальше. Привязан к текущему стеку (React + тонкий PHP/MySQL, видео Kinescope, ИИ через routerai.ru) и к тому, что **уже есть в коде** — поэтому большинство пунктов опирается на готовый фундамент.

Обозначения трудоёмкости: **S** — день-два, **M** — неделя, **L** — две недели и больше.

---

## 🔥 Топ-5 (самые ценные на старте)

1. **Онлайн-оплата подписки (ЮKassa)** — сейчас доступ открывается вручную через заявку. Реальная оплата = меньше ручной работы и выше конверсия. **L**
2. **Самостоятельное восстановление пароля** — сейчас «напишите куратору». Базовая вещь, которой ждут все. **M**
3. **Email/Telegram-уведомления** — сейчас уведомления только в колокольчике внутри сайта. Дублирование в TG/почту резко поднимает возвраты учеников. **M**
4. **Прогресс-бар курса и «продолжить с того места»** — у нас уже есть `lesson_progress`, осталось показать процент прохождения и кнопку «продолжить». **S–M**
5. **Промокоды на подписку** — в футере уже заявлены «Промокоды»; даёт инструмент для акций и партнёрок. **M**

---

## 💰 Монетизация

- **Оплата подписки онлайн (ЮKassa/Робокасса)** — эндпоинт чекаута + вебхук, активация подписки автоматически (логика уже есть в `admin_subscription_set`). **L**
- **Промокоды и скидки** — таблица `promo_codes`, применение при оформлении тарифа. **M**
- **Партнёрская/реферальная программа** — в футере заявлена; реф-ссылка ученика, бонус кристаллами или скидкой за приведённого друга. **M**
- **Покупка отдельных курсов** (не только тарифом) — разовая оплата доступа к одному предмету. **M**
- **Рассрочка/частичная оплата** — пометка тарифов «можно частями». **S** (контент) / **L** (если через банк).

## 🎮 Вовлечение и геймификация (фундамент уже есть)

- **Таблица лидеров / рейтинг** — у нас есть кристаллы и серия; добавить недельный/общий рейтинг учеников (можно по предмету). **M**
- **Заморозка серии (streak freeze)** — товар в магазине, который спасает серию при пропуске дня. Магазин уже готов. **S**
- **Цели и челленджи на неделю** — «реши 5 ДЗ за неделю → +200 кристаллов». Расширение «Заданий дня». **M**
- **Сертификат о прохождении курса** — генерация PDF при 100% прогрессе (`lesson_progress` уже считает). **M**
- **Бейджи за стрики и предметы** — расширить каталог достижений (он уже есть и редактируется в админке). **S**

## 🤖 Качество обучения и ИИ (у нас уже подключён ИИ)

- **ИИ-предпроверка развёрнутых ответов (сочинения/задачи части 2)** — сейчас они идут на ручную проверку; ИИ может давать черновую оценку и комментарий до куратора. **M**
- **Адаптивная сложность в тренажёре** — подстраивать уровень задач под результаты ученика (есть `trainer_attempts`, `bank_progress`). **M**
- **Интервальное повторение (spaced repetition)** в банке заданий — возвращать ошибочные задачи через N дней (данные о решённом уже копятся). **M**
- **Персональный план подготовки** — ИИ строит маршрут «слабые темы → что решать» по статистике ошибок. **L**
- **Голосовой ассистент-репетитор** — мы уже добавили голосовой ввод; можно озвучивать ответы ИИ (TTS). **M**
- **Разбор ошибок одной кнопкой** — после теста «объясни, почему я ошибся» через ИИ по конкретным вопросам. **S–M**

## 📊 Аналитика и личный прогресс

- **Дашборд прогресса ученика** — графики по предметам, слабые темы, динамика баллов пробников. **M**
- **Прогноз балла ЕГЭ/ОГЭ** — оценка по результатам пробников и ДЗ. **M**
- **Админ-аналитика** — отток, активность, конверсия заявок (раздел «Заявки» уже есть), средний прогресс по курсам. **M**
- **Отчёт родителю** — еженедельная сводка успеваемости на email/в кабинет (см. «Родителям» ниже). **M**

## 👨‍👩‍👧 Аудитория и рост

- **Личный кабинет родителя** — в меню лендинга уже есть пункт «Родителям»; отдельный вход с просмотром прогресса ребёнка. **L**
- **Telegram-бот для учеников** — у вас уже есть TG-бот предзаписи; расширить до напоминаний о дедлайнах и быстрых вопросов. **M**
- **SEO лендинга** — мета-теги, OpenGraph, sitemap, страницы под запросы «ЕГЭ по <предмету>». **M**
- **Публичный «открытый банк заданий»** (в футере заявлен) — демо-задачи без регистрации как точка входа/SEO. **M**
- **Реальные кейсы/истории учеников** — расширить блок отзывов с видео. **S**

## 🛠️ Админка и операционка (узкие места из аудита)

- **Массовый импорт вопросов (CSV/Excel)** в банк/ДЗ/пробники — сейчас вопросы заводятся по одному, это долго. **M**
- **Картинки в вопросах** (формулы, графики, схемы) — критично для математики/физики/химии. **M**
- **Черновики/публикация контента** — редактировать курс, не показывая ученикам, пока не готово. **M**
- **Ответы куратора с вложениями** — мы добавили вложения от ученика; симметрично дать вложения и куратору. **S**
- **Шаблоны рассылок и сегменты** — слать уведомление не всем, а группе (по курсу/тарифу). **M**
- **Журнал действий админа (audit log)** — кто что менял. **S–M**

## 🔐 Надёжность и техника

- **Двухфакторная аутентификация для админа** — защита критичной панели. **M**
- **PWA / установка на телефон** — офлайн-доступ к конспектам, иконка на экране. **M**
- **Поиск по контенту** — глобальный поиск по урокам, материалам, банку. **M**
- **Тёмная тема** — приятная мелочь для вечерних занятий. **S**
- **Бэкапы БД по расписанию** + выгрузка результатов в PDF/Excel. **S–M**
- **Доступность (a11y)** и адаптив под маленькие экраны — добивка по месту. **S–M**

## Что стоит сделать первым (моё мнение)

Если по приоритету «деньги → удержание → рост»:

1. Онлайн-оплата + промокоды (деньги, меньше ручной работы).
2. Восстановление пароля + email/TG-уведомления (удержание, базовая гигиена).
3. Прогресс-бар курса + дашборд ученика (видимый прогресс держит мотивацию).
4. Массовый импорт вопросов + картинки в вопросах (снимает боль наполнения контента).
5. ИИ-предпроверка развёрнутых ответов (разгружает кураторов, ваша сильная сторона — ИИ уже подключён).
