# Какой блок открывается при входе в курс

С 14 октября 2026 года обычное открытие курса временно показывает первый
период программы независимо от текущей даты. Это первый элемент `months`
в ответе `course_get.php`: сервер сортирует периоды по `position`, затем по `id`.
Для годовых курсов 2026/27 это «БЛОК 1». Правило также действует для курсов,
у которых периоды называются месяцами.

Переключатель находится в `src/coursePeriod.js`:

```js
export const AUTO_SELECT_COURSE_PERIOD_BY_DATE = false
```

`CourseInside.jsx` использует этот переключатель в `currentMonthIdx`.
При `false` начальный индекс периода равен `0`.

## Как вернуть прежний выбор по датам

1. Поставить `AUTO_SELECT_COURSE_PERIOD_BY_DATE = true`.
2. Собрать и загрузить обновлённый фронтенд на действующие домены.

Алгоритм выбора по датам сохранён в `currentMonthIdx`:

- используется серверная дата `today` по московскому времени;
- выбирается первый период, для которого `starts_on <= today` и дата не
  позже `ends_on`; отсутствие `ends_on` означает открытый диапазон;
- если подходящего диапазона нет, выбирается последний в порядке программы
  период с `starts_on <= today`;
- если ни один период ещё не начался или серверная дата отсутствует,
  выбирается первый период.

## Остальное поведение

Ручной выбор другого блока продолжает работать. Прямая ссылка на урок,
например `#courses/15/192`, открывает период этого урока: явный переход к
занятию имеет приоритет над выбором блока по умолчанию. Обновление страницы
с такой ссылкой также возвращает к уроку.

Даты блоков, расписание, даты открытия уроков, материалы и домашние задания
этот временный переключатель не меняет. Обновление данных курса из админки
сохраняет уже выбранный учеником период.
